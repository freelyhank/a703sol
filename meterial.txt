PRODUCT
ORAsol is an independent Solana community application presented as a public
register. It supports an overview, quests, token status, advisory governance,
treasury reads, and a field guide. Routes remain
#home / #quests / #stake / #governance / #treasury / #learn.

The Anchor community program records quest participation and advisory votes.
It does not mint or distribute tokens, implement token locks, or execute
treasury spending. No token mint or token symbol is configured.

VISUAL
Daylight paper surfaces (#f2ebdf stock, #fffdf8 cards) with warm ink text
(#1c1710), a pine structural signal (#14503f) and a marigold solar signal
(#b1741a); failures use a muted maroon (#8b3a32). Display type is a printed
serif (Iowan Old Style / Palatino / Georgia stack) set large and tight;
interface text is a neutral sans. Corners are soft (12-26px), elevation is a
low warm shadow, and the page carries faint radial washes at the top.
The ORAsol mark is the Solar O: a pine register ring closed around an open
counter with a marigold sun in the 1:30 opening, used as favicon, masthead
glyph, footer glyph and social avatar. The wordmark is a true vector serif with
"sol" in marigold. Mono type, acid lime, hairline rules and the ledger monogram
are retired.

INTERFACE STRUCTURE
A single centred column under a sticky horizontal masthead: ORAsol wordmark at
the left, six icon pills for the sections in the middle, cluster chip, refresh
and wallet on the right. Below the masthead, status appears as soft banners only
when something needs saying. Every section opens with a serif page title, a lede
and meta chips, then composes from rounded cards: quest grids, ballot cards with
split tally bars, receipt-style statements, timelines and accordions. A
deep-pine feature tile separates "take part" from "weigh in" on the overview. On
small screens the pills leave the masthead, a right-hand drawer carries the
sections and the wallet, and the footer stacks. The retired fixed left spine,
numbered navigation, sticky command strip, table rows and bottom tab bar are not
used.

Twitter launch material consists of five posts: one brand statement, one
participation post, one advisory-vote post, one register read, and one guide
note. No post carries a contract address; no token mint exists.
