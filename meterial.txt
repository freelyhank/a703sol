PRODUCT
Tabulora is an independent Solana community application with a ledger-terminal
interface. It supports a register overview, quests, token status, advisory
governance, treasury reads, and a field guide. Routes remain
#home / #quests / #stake / #governance / #treasury / #learn.

The Anchor community program records quest participation and advisory votes.
It does not mint or distribute tokens, implement token locks, or execute
treasury spending. No token mint or token symbol is configured.

NETWORK

Program address and account interface are preserved. The deployed Anchor

VISUAL
Black ledger surfaces with hairline rules and a single acid-lime signal
(#c8f04a) plus a burnt counter-signal (#ff6a3d). Labels are tracked monospace.
The Ledger Monogram, a T and an A cut from record plates with one counter still
open, is used across the app and launch materials.

INTERFACE STRUCTURE
A fixed left navigation spine carries the six numbered sections; a sticky
command strip shows cluster, program, open quests, open votes and mint state;
content is built from record tables, definition lists and numbered steps. On
small screens the spine collapses into a bottom tab bar. The retired centred
top-navigation layout, hero panel and rounded card grid are not used.

Twitter launch material consists of five posts: one brand statement, two build
posts, one ledger read, and one guide note. No post carries a contract address;
no token mint exists.
